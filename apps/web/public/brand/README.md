## How to Add the Official Asset
When the official `bop-clients-logo.svg` vector asset is supplied by the brand team / user, place the file directly at:
```
apps/web/public/brand/bop-clients-logo.svg
```

The `BrandLogo` component automatically detects and renders this file if present.
Until then, the application strictly displays the neutral typographic fallback:
```
BOP | CLIENTS
```
No substitute icons, geometric node shapes, or fabricated symbols are permitted.
